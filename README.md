# Dody Fernanda — Senior Purchasing & Procurement Professional Portfolio

Website portofolio profesional untuk **Dody Fernanda** — Senior Purchasing, Procurement Professional, Supervisor, dan Cost Control Specialist dengan 12+ tahun pengalaman lintas industri (ALSOK Indonesia, A3000 Group, Charoen Pokphand, Victoria Care, CGV Cinemas, dan KFC).

Dibangun menggunakan **Next.js 16 (App Router & Turbopack)**, **Tailwind CSS v4**, **Framer Motion**, dan **Lucide Icons**.

---

## 🚀 Fitur Unggulan

- **Hero Section**: Profil eksekutif, foto resmi berlatar jas formal, quick stats (*12+ Years Experience*, *6 Leading Companies*, *COGS Governance*), dan tombol aksi cepat ke WhatsApp/Email.
- **Achievement Highlights**: 6 metrik pencapaian interaktif lengkap dengan modal popup detail riwayat perusahaan dan kompetensi pengadaan.
- **Value Proposition**: 6 pilar nilai strategis pengadaan, dari *Vendor Sourcing*, *Commercial Negotiation*, *COGS Governance*, hingga *Inventory Control*.
- **Featured Portfolios & Case Studies**: Galeri studi kasus interaktif berfilter kategori lengkap dengan ilustrasi SVG dasbor pengadaan, tantangan (*challenges*), dan solusi bisnis (*solutions*).
- **Core Competencies & Stack**: Pemetaan keahlian spesialisasi, metodologi rantai pasok, kepemimpinan SDM (S2 Magister HRM), serta penguasaan advanced spreadsheet & ERP.
- **Experience Timeline**: Linimasa karier mendalam mencakup 6 perusahaan bereputasi tinggi sejak 2012 hingga saat ini.
- **Procurement & Supply Chain Operations Hierarchy**: Visualisasi struktur operasional rantai pasok dengan fitur interaktif *reveal team*.
- **Education & Credentials**: Riwayat pendidikan S1 & S2 Magister Manajemen SDM di Universitas Pamulang serta sertifikasi kompetensi.
- **Contact & Availability**: Formulir kontak interaktif, info ketersediaan rekrutmen/proyek, tautan LinkedIn, serta unduhan dokumen PDF CV asli.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & MDX)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 💻 Menjalankan Project

### 1. Development Mode
```bash
npm run dev
```
Buka browser di [http://localhost:3000](http://localhost:3000).

### 2. Production Build
```bash
npm run build
npm run start
```
